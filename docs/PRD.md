# DuoChat v1.0

## Tujuan

Aplikasi chat pribadi untuk dua pengguna.

## Target User

Hanya dua orang.

## Fitur

- Login
- Register
- Chat realtime
- Online status
- Read status
- Edit profile

## Tidak termasuk

- Group
- Voice Call
- Video Call
- Story
- Broadcast
- File Sharing (v1)

## Tech Stack

- Laravel
- MySQL
- Tailwind CSS
- Laravel Reverb (Realtime)
